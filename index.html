A window,
not a tab.

DiskLens is a real desktop app: one file, its own window and icon, no server and no browser. It runs on Windows and macOS, and it tells you when a newer version is out.

Get it.

A per-user install, no elevation, nothing written outside your profile. Nothing to install first.

Windows
  1. Download DiskLens-Setup.exe (about 65 MB) and run it. It installs for you only, into %LOCALAPPDATA%\Programs\DiskLens.
  2. DiskLens lands in the Start menu, and on the desktop if you leave the box ticked.
  3. It checks for a newer release when it opens and offers Update now. One click, and it reopens updated.
  4. Remove it from Add/Remove Programs. The saved index stays in %LOCALAPPDATA%\DiskLens until you delete it.

Needs Windows 10 or 11 with WebView2, which ships with Edge.

macOS, or from source 
# needs the .NET 8 SDK
git clone https://github.com/Sachin1724/DiskLens
cd DiskLens

dotnet publish app -c Release -r osx-arm64
sh app/bundle-mac.sh        # -> DiskLens.app

# the checks that guard it
dotnet run --project app -- --selftest
node check.js && node check-ui.js

No prebuilt Mac app is published yet, and the Mac build has not been tested on real hardware. The scanner, rules and window are the same code as on Windows.
