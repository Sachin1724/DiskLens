A squarified treemap of the folder you are in. Loose files get a block of their own, so a 36 GB pagefile stops hiding behind a folder list.

02

Copies

Size buckets first, then only the collisions are read: 3.2M files seen, 462 hashed, 31.1 GB of the same bytes in more than one place.

Hotspots

The biggest folders anywhere on the drive, with pure containers filtered out so you get the culprit, not its parent.

04

Table

The same numbers, sortable, keyboard-navigable. A treemap on its own is a poor experience without a mouse.

06

Recycle Bin, always

Nothing is deleted outright. Deletes patch the index in place, so the numbers update in 0.3 s instead of another sweep.

Get it.

A per-user install, no elevation, nothing written outside your profile.

The installer
  1. Download DiskLens-Setup.exe and run it. It installs for you only, into %LOCALAPPDATA%\Programs\DiskLens.
  2. DiskLens lands in the Start menu, and on the desktop if you leave the box ticked.
  3. Remove it from Add/Remove Programs. The saved index stays in %LOCALAPPDATA%\DiskLens until you delete it.

Needs PowerShell 7: winget install --id Microsoft.PowerShell. DiskLens says so if it is missing.

Or from source 
pwsh -File DiskLens\server.ps1

# the checks that guard it
pwsh -File DiskLens\server.ps1 -SelfTest
